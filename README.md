# Tbilisi parking survey - plan v3 viewer

Static map of the cleaned survey days (the days on STS NAV) and the plan v3 days not yet reviewed, with the City Hall and proposed
parking lots and the streets filmed on 14 Oct. Built from `GPX_Google` on the `gpx-improver` branch
(`uv run python -m gpx_google.site`); this branch holds only the built page.
